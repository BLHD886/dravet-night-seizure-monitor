# Dravet 软件链路开发原型

Python 3.11+，只用标准库，无第三方依赖。支持合成演示和 CSV 历史导入；不是已发布 Android App 或已部署的云服务。请先读 ../PROJECT_STATE.md 和 ../outputs/Dravet软件兼容方案V3.md。

## 运行

在本目录运行：

```powershell
python server.py
```

本机打开 http://127.0.0.1:8765 。首次启动在 runtime/dev-token.txt 创建随机开发访问码，复制到页面的连接框；访问码不写入前端持久存储或打印到日志。runtime/demo.sqlite3 是本地演示库，重启保留数据。

需要 Android 手机在同一 Wi-Fi 打开时：

```powershell
python server.py --host 0.0.0.0
```

手机访问 http://电脑局域网IP:8765 ，输入相同开发码。局域网可达性取决于防火墙和网络隔离，当前未自动更改 Windows 防火墙。HTTP LAN 模式仅用于无真实个人信息的开发测试，不要暴露公网。手机浏览器与电脑各自拥有独立 IndexedDB 数据；电脑 SQLite 是两端共享的后端数据库。

演示顺序：连接 → 生成模拟样本 → 事件页演练一级/二级 → 我已查看/我来接手 → 家长标签 → 记录页保存演示观察 → 助手页查看最近一小时摘要。

页面刷新或关闭需要重新输入开发码。未配置 AI 时不勾选授权框可得到“本地摘要（非 AI）”；勾选后若没配置模型，会明确失败。浏览器本地缓存不等于完成断网监护，本轮不做断网验收。

## CSV 与可选 ACC

连接后打开“数据”页：载入合成示例，或选择 UTF-8 CSV → 选择原始类别、时间格式、可选列映射 → 预览校验 → 确认导入。页面会列出数据范围、心率/ACC/雷达样本数与错误行。若文件有错误，不部分写入；同一内容与解析参数重复导入幂等。

最小列为 timestamp、heart_rate；device_id 可选。时间必须有时区，或在页面显式填写 +08:00 等偏移。也可选择 Unix 秒/毫秒。列映射例：{"timestamp":"时间","heart_rate":"心率"}。

ACC 可完全省略；提供时必须有 acc_x、acc_y、acc_z 和 acc_unit（g 或 m/s2）。当前没有运动算法。有步数不表示原始 ACC 可用。雷达区域列为 area0..area3，提供时四区齐全。

导入源固定为 replay，原始类别另存；守护页合成当前值不会被历史 CSV 替换，也不触发告警。助手页可选择 CSV 原始时间范围摘要；未提供真实文件，本轮使用合成 CSV 验证。任意导出格式不是自动兼容，未识别字段会列出，必要时补映射。Da Fit 导出能力未验证。

开发库仅用于测试，不代表已具备存放真实健康数据的正式权限与加密体系。默认不要在演示环境填写可识别患者信息。

## 真实 AI 配置

服务端读取 ASSISTANT_URL、ASSISTANT_MODEL、ASSISTANT_KEY 环境变量。URL 必须是完整 chat-completions 风格端点；适配请求为 model/messages，响应为 choices[0].message.content。使用 HTTPS，或本机回环 HTTP。不要把密钥发到聊天、写进前端或提交仓库；在私有服务配置中设置。

真实模型仅在页面明确同意后发送所选窗口摘要与问题。可选合成演示最近一小时或最近导入 CSV 的原始时间范围；CSV 不混入当前监测窗口。未配置、失败或空响应不会制造假回答。真实模型调用尚未实测；需确认上游禁用工具和长期记忆。本轮同步等待最多 25 秒，正式云端改为持久任务队列与授权撤回检查。

## 模块替换

- server.py 的 /v1/demo/tick 是显式模拟数据源，不是硬件驱动。腕表协议补齐后增加真实接收路径；最新产品参考 P8 SE，报告固件 MOY-JK62-2.0.5 / Da Fit 不足以确认协议兼容。
- ld6004.py 是协议解码原型：先用 Decoder.feed(bytes) 验证录制串口，再接 SerialTransport；真实串口接入尚未实现。
- /v1/samples 是版本化批次接口原型，仅接受 synthetic。正式设备路径需补设备身份、家庭权限、schema 校验与真实来源管理。
- web/ 是 Android 浏览器交互原型；迁移 Flutter 时保留 API 契约，将 IndexedDB 换 Room/SQLite，将前台轮询换实际推送/查询补偿。
- 本服务只有单个演示家庭访问码；正式账号/家庭隔离、HTTPS、数据库迁移、PostgreSQL 部署未实现。
- PRD 一级/二级提醒现以事件列表和回执演练；未实现床旁灯光/声音、手机锁屏推送或后台响铃。

LD6004 当前协议没有呼吸率或心率输出。区域无人不能被当成呼吸停止，目标 ID 不能当成孩子身份。医学算法与个体基线均未实现。

## 验证

```powershell
python -m unittest -v test_core.py
```

覆盖官方空点云帧、分包/粘包、校验错误恢复、载荷长度、未知消息保留、访问码与跨域拒绝、去重与数据库重新打开、两级事件和独立反馈、观察重试、助手降级。合成测试不能证明设备、临床性能、Android 后台送达或真实模型可用性。
